# Release 0.3.2 candidate preparation

Local and platform automated gates and package inspections pass. The aggregate
is **Untested** because the remaining native acceptance coverage is unverified. This is
preparation evidence, not publication or a claim that the complete release matrix
passed. See [scope and notes](../../development/release-0.3.2.md).

## Build and scope

macOS Apple silicon; pinned Rust 1.96.0; version 0.3.2. Product changes are in
`742ac21e` (workspace chrome) and `0fa2a313` (notification context), with the version
bump still uncommitted when local checks ran. The [manifest](../../evidence/2026-10-19-release-0.3.2/manifest.json)
records the exact revision, dirty diff hash, source hashes and sidecar digest.
Subsequent preparation records do not change the tested product code.
The [candidate comparison](../../evidence/2026-10-19-release-0.3.2/candidate.json)
confirms all 327 tracked source/build files match candidate
`4afea26f5bd2fc168675e0b58aa731324c1bea1f`. The local DMG records `0fa2a313` because
packaging started before the version commit; its build used the same versioned
source tree. Candidate CI/package jobs use `4afea26f` directly.

Selected scope: [views](../../features/workspace-views.md),
[panes/attention](../../features/panes.md), [settings](../../features/settings.md)
and [distribution](../../features/distribution.md). No personal app/profile was
opened or controlled. The live-session suite owns temporary `/tmp/cr-*` Herdr
namespaces and tears down its own processes. Notification desktop testing remains
explicitly deferred following the user's session-disruption report.
