## Question 3

```text
Round: Agent attention and desktop notifications — round 1
Question: What counts as visiting a session and clears its dot?
Description (Markdown source):
A terminal may be visible in a split without being the terminal you are reading. An active window means Chartr is in the foreground.
Recommendation: Clear the dot when that terminal receives focus in an active window; merely appearing in an adjacent split should not clear unseen attention.
Options: Focus the terminal in an active window / Show the terminal anywhere in an active window / Type into the terminal or explicitly mark it seen
```

## Question 4

```text
Round: Agent attention and desktop notifications — round 1
Question: When should a completed or waiting agent send a desktop notification?
Description (Markdown source):
This determines whether notifications also help when you are working in a different Chartr tab. New events would be deduplicated so unchanged states do not repeatedly notify.
Recommendation: Notify whenever that terminal is not focused, or Chartr is inactive, including when you are working in another Chartr tab.
Options: Whenever that terminal is not focused, or Chartr is inactive / Only when Chartr is in the background / Always, including the focused terminal
```

## Question 5

```text
Round: Agent attention and desktop notifications — round 1
Question: If an agent has no reliable completion or waiting signal, which tradeoff do you prefer?
Description (Markdown source):
Quiet terminal output can mean an agent is still thinking. A timer alone cannot reliably establish that its turn is finished.
Recommendation: Avoid false alerts and leave uncertain states unknown until dependable detection is available.
Options: Avoid false alerts; leave uncertain states unknown / Use best-effort guesses, accepting occasional false alerts
Selected: Avoid false alerts; leave uncertain states unknown
Notes: 
```

```text
Round: Agent attention and desktop notifications — round 1
Question: Where should unseen attention appear when a terminal is hidden inside a group or another space?
Description (Markdown source):
A dot on an enclosing group or space would mean at least one contained terminal has unseen attention. Opening that container would not itself acknowledge every terminal.
Recommendation: Show dots on the terminal tab, enclosing group, and space so you can locate attention without opening everything.
Options: Terminal tab, enclosing group, and space / Terminal tab and enclosing group only / Individual terminal tab only
```

```text
Description (Markdown source):
Hiding, minimizing, or closing a window can leave the app running. Fully quitting ends the app process; notifying after that would require another background owner.
Recommendation: Require Chartr to remain running, including while hidden or minimized, for this change.
```
