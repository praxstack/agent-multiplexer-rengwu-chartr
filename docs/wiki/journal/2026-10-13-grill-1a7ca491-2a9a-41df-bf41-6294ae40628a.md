## Question 14

```text
Round: Herdr changes
Question: How should we maintain these changes?
Description (Markdown source):
Herdr needs to:
- Distinguish completion, cancellation and failure.
- Identify events so alerts are not duplicated or lost on reconnect.
- Preserve attention state during backend upgrades.

A plugin receives the same incomplete status data. To avoid changing Herdr, it would need its own agent integrations.

Dots and desktop notifications stay in Chartr.
Recommendation: Keep a patch in Chartr. Detection stays in Herdr; we maintain the patch when upgrading it.
Options: Keep a Herdr patch in Chartr / Maintain a separate Herdr fork / Explore a plugin with its own agent integrations / Wait for upstream support
Selected: Keep a Herdr patch in Chartr
```
